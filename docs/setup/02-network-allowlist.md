## 为什么需要
Claude 的云端环境默认不能访问外网。为了真的下载游戏、安装加载器、启动游戏来测试，需要放行这些网站：

- Mojang：`piston-meta.mojang.com`、`piston-data.mojang.com`、`launchermeta.mojang.com`、`launcher.mojang.com`、`libraries.minecraft.net`、`resources.download.minecraft.net`
- 加载器：`meta.fabricmc.net`、`maven.fabricmc.net`、`meta.quiltmc.org`、`maven.quiltmc.org`、`maven.minecraftforge.net`、`files.minecraftforge.net`、`maven.neoforged.net`
- Java：`api.adoptium.net`、`github.com`、`objects.githubusercontent.com`、`release-assets.githubusercontent.com`
- 模组网站（阶段 2、3 用）：`api.modrinth.com`、`cdn.modrinth.com`、`api.curseforge.com`、`edge.forgecdn.net`、`mediafilez.forgecdn.net`

以后在 claude.ai 上新开 Cairn 的对话时，选 `cairn` 这个环境就行。
